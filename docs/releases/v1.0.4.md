首个公开版本：Saleae Logic 2 的 TCS / PROG SPI 高级分析器。

## 功能

- TCS 读写、请求/应答关联及同 CS 轮询数据解析。
- PROG 寄存器访问、CRC 校验和特殊序列识别，包含 `0x83` 扩展 Die。
- 自动识别请求方向；简洁波形文字；统一 CMDID 列和十进制事务编号。
- 中文 README、协议说明和 MIT 许可证。

## 安装

下载并解压 `TCS_PROG_SPI_v1.0.4.zip`，在 Logic 2 的 Extensions 中加载 `extension.json`。输入选择 SPI 低级分析器，配置 8 位、MSB first 和有效 CS；参考采样使用 Mode 0、CS 低有效。

## 验证

21 项单元测试与 56 项参考断言通过；回放 2,610 个参考事务并正确报告已知输入异常。`0x83` 使用合成输入验证。用户提供的截图确认插件可在 Logic 2 显示；最终打包版本未做完整 GUI 自动化验收。

`SHA256SUMS.txt` 用于校验安装包。原始采样和本地详细诊断数据不包含在发布包内。
